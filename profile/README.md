# LynxOffice

**A native office suite for Mac and Windows, with on-device AI.** Powered by KDAN.

LynxOffice opens, edits and saves Word, Excel, PowerPoint and PDF files in their original format. It never uploads your documents, and its AI tools run on your device. Learn more at [lynxoffice.com](https://lynxoffice.com).

## For AI agents and scripts

| Repository | What it is | Install |
|---|---|---|
| [lynxoffice-mcp-mac](https://github.com/LynxOffice/lynxoffice-mcp-mac) | An MCP server that lets Claude, Codex or any MCP client read, edit and review your documents on your Mac | `brew install lynxoffice/tap/lynxoffice-mcp` |
| [lynxoffice-cli-mac](https://github.com/LynxOffice/lynxoffice-cli-mac) | The `lynxoffice` command, for Terminal and scripts | `brew install lynxoffice/tap/lynxoffice` |
| [homebrew-tap](https://github.com/LynxOffice/homebrew-tap) | The Homebrew formulae for both | |

Both need macOS 14 or later, on Apple silicon or Intel.
